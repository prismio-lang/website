Prismio 0.2.0 was released on 2026-11-10. It remains a pre-1.0 release rather than a stability promise. The user-facing notes, with downloads and the breaking changes, are the [docs site's release page](https://docs.prismio.org/releases/0.2.0); this page records what changed inside the compiler, the runtime and the build, for people who read or change them.

## Compiler and tooling

- **A language server in the compiler.** `prismio lsp` speaks LSP 3.17 over standard input and output. Diagnostics come from `prismio check --partial` over the program an edited file belongs to, with every open document's unsaved text overlaid. The server answers hover, definition, type definition, references, highlights, outline, workspace symbols, completion across the library and semantic tokens, and it serves `build.ums`. See [the language server](/tooling/language-server).
- **A semantic index.** `check <entry> --emit-index <file>` writes JSON Lines after the run: every declaration, and what the compiler lowers instead of declaring (a `Vec`'s methods, builtins). Editors read it instead of keeping their own tables.
- **A formatter.** `prismio fmt` lives in `src/fmt/`, moved out of the IntelliJ plugin's `SpacingBuilder` so an editor, the server and CI share one set of rules. It changes whitespace only, which the output proves by having the input's tokens.
- **`prismio dump-tokens`** prints the lexical vocabulary as JSON, and the plugin's lexer tables are held to it.
- **Error recovery.** The parser drops the statement it cannot read, and a syntax error in an `impl` or `trait` drops one method. The frontend no longer ends the run at the first lexical, syntax or import error, and `check --partial` type checks what parsed.
- **The version lives in `build.ums`.** `project.version` is read through `import build`, and `build.ums` gains `const` and `enum`. A release is bumped in one place.
- **Checker lookups answer from an index.** `src/sema/decl_index.psm` replaced three lookups that walked the whole program per annotation, and the compiler's self-build went from 2.51 s to 1.37 s.

## Language and memory

- **Async.** An `async fn` call builds a `Future<T>` and the body runs where it is awaited; `await f(x)` is the call itself. `spawn` takes an `async fn` and a scalar argument or result of any width through a thunk. `scope { }` and `spawn { }` are lowered with the scope waiting on every task on every way out.
- **Typed pointers.** `Ptr<T>` was built in six stages: the type, reads, writes, motion, volatile and atomic access, and typed blocks. What a `Ptr<T>` lets the optimiser assume was audited, and four assumptions were wrong and fixed.
- **Integers of any width.** `Int<N>` and `UInt<N>` lower to `iN`, with five float types, and arithmetic wraps or traps at the width.
- **Variadics and `typelist`.** A pack is solved over a `typelist`, which is how `std.io` became four functions instead of about a hundred overloads.
- **`Option<T>` was removed** in favour of `T?`, and `Map` became `HashMap`.
- **Index checks.** An index out of range on a `Vec` or an `Array<T, N>` stops the program; a constant one is a compile error, and an index the compiler proves in range has no check.
- **AIF is Prismio.** `runtime/aif_support.c` and `aif_containers.c` (9,248 lines of C) were replaced by the `src/aifcore` package of 18 modules. `runtime/ir_symbols.c` and `runtime/diagnostics.c` followed.

## Runtime and build

- **Freestanding builds.** A `--freestanding` program links static with `ld.lld` and no runtime, C library or startup files. The failure core in `runtime/freestanding/panic.c` forwards to `prismio_panic_hook`, and a program that supplies `prismio_alloc`, `prismio_realloc` and `prismio_free` gets a heap for `Vec`, `String`, `HashMap` and `std.mem`.
- **System calls.** `__builtin_syscall` is lowered in place to the target's instruction sequence, with a failure reported as `-errno` everywhere. The named tables are generated by `tools/gen_syscalls.py` from the kernels' own headers.
- **A slab allocator** sits behind `rt_base_alloc` on 64-bit macOS and Linux: a 64 GiB reservation carved into 64 KiB spans, 32 size classes from 16 to 512 bytes, and thread-local caches. Windows keeps its recycler.
- **The pipeline.** The second half of the default IR pipeline runs in the codegen partitions in parallel, the runtime and library bitcode is merged lazily on macOS and Linux, and a macOS program links by running `ld` directly with chained fixups. Prismio's own passes run at the vectorizer extension points on freestanding code.
- **LLVM 23.1.5** is the pinned backend line, with checksummed archives per platform.

## Known limits

- A task is still an operating-system thread. `await` blocks its thread when the task runs elsewhere, and a held future or task takes at most three arguments.
- The Windows halves of `std.poll` are not built or run in the project's own tests, and Windows is the least exercised platform.
- Some temporary shapes still leak under `--verify`, with no violation.

`docs/KNOWN_ISSUES.md` in the compiler repository is the list of what is open.
